# ***Heart Disease & MNIST ML Pipeline***

This repository contains the complete ML pipeline and deployment application for the DS-3002 Data Mining Assignment #4. 
The project demonstrates unsupervised learning, ensemble methods, tabular neural networks, and convolutional neural networks applied to the UCI Cleveland Heart Disease dataset and MNIST digits.

## ***Folder Structure***
- `/data/`: Contains the raw data file (`processed.cleveland.data`).
- `/notebooks/`: Contains the fully executable Jupyter notebook (`assignment4_full_pipeline.ipynb`) and the python script used to generate it.
- `/app/`: Contains the Streamlit dashboard (`app.py`), the saved Random Forest model, and the preprocessor pipeline.
- `/figures/`: Contains all generated charts and visualizations organized by section.
- `/outputs/`: Contains all tabular metrics and results generated by the pipeline.
- `/report/`: Contains the final project report (`assignment4_report_draft.md`).

## ***How to Run the Notebook***
To reproduce all figures, tables, and models:
1. Ensure your environment matches the `requirements.txt`.
2. Navigate to the `/notebooks/` directory.
3. Open `assignment4_full_pipeline.ipynb` in Jupyter Notebook/Lab.
4. Go to **Kernel -> Restart & Run All**.
5. Wait for the execution to finish. Results will automatically save into `/figures/` and `/outputs/`.

## ***How to Run the Streamlit Dashboard***
1. Ensure dependencies from `requirements.txt` are installed.
2. Navigate to the root directory of this project.
3. Run `streamlit run app/app.py`.
4. The dashboard will automatically open in your local web browser.

## ***Dataset Download / Source Instructions***
The Cleveland Heart Disease dataset is already provided within `/data/`. 
The MNIST subset is loaded directly via TensorFlow's datasets API.

## ***Notes on Random Seeds***
For strict reproducibility, random seeds for Python `random`, `numpy`, `scikit-learn`, and `tensorflow` have all been fixed to `42` at the beginning of the notebook.
